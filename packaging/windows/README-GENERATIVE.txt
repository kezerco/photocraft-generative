PhotoCraft Generative Fill fork — UNSIGNED Windows x64 preview
https://github.com/kezerco/photocraft-generative

Extract every file in this archive into one folder, then double-click START-PHOTOCRAFT.cmd (not photocraft.exe). At the fal.ai prompt, paste your own key ONCE and press Enter; it will not appear while typing. The launcher passes it to this run of PhotoCraft without saving it to a file. Make your own fal.ai account at https://fal.ai/dashboard/keys and check prices before editing. Each confirmed request may be billed even if it fails.

Open an 8/16-bit RGB image, select a small area, then Edit > Generative Fill. The default prompt is "Make it realistic". FLUX.1 Pro Fill accepts a true mask; FLUX.2 Pro and Gemini Pro use a selection guide, and may not obey it. The result is an undoable layer; Edge Pixels controls its soft boundary. Try copies of images first.

This is a community fork, not an official PhotoCraft release. The program is unsigned; Windows or your organization may block it. Do not bypass organizational policies. The cloud API receives the render crop, mask and prompt; never share your key or upload private renders without permission. 32-bit HDR and non-RGB input are not supported. See docs/generative-fill-fork.md in the source repository for limitations and build instructions.

portable.txt causes preferences/autosaves to stay next to this executable in PhotoCraftData. To disable portable mode, remove portable.txt. PhotoCraft is MIT OR Apache-2.0; bundled licenses are included.
